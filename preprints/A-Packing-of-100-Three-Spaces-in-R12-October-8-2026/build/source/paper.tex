\begin{abstract}
We give 100 3-dimensional subspaces of $\mathbb{R}^{12}$ whose smallest squared chordal distance is at least 2.193244. This cell of the table of best Grassmannian packings has no published value. No packing with more three-spaces in this row gives a value to compare with. The value is checked with exact rational arithmetic from integer coordinates. We do not claim it is optimal.
\end{abstract}

\section{Result}
\begin{theorem}
There are 100 subspaces of dimension 3 in $\mathbb{R}^{12}$ whose pairwise squared chordal distances $D(a,b) = 3 - \operatorname{tr}(P_aP_b)$ are all at least
\[ D_{\min} = 2.193244\ldots \]
\end{theorem}
The exact value of $D_{\min}$, a rational number, is given in Appendix~A.


\section{Context}
N.~J.~A.~Sloane's \emph{Table of Best Grassmannian Packings} (last modified 1997), now maintained by Henry Cohn, lists values for some $N$ in the row $m=12$, $n=3$. The cell $N=100$ is blank in Sloane's table, in Sloane's coordinate files and in Cohn's table as checked on October 8, 2026. No packing with more three-spaces in this row gives a value to compare with. The Rankin simplex bound for this cell is $3(12-3)/12\cdot 100/99 = 2.272727$, and the value above lies below it.


\section{Verification}
Each subspace is given by an integer $m\times n$ basis $Y$ (coordinates times $10^{12}$, rounded). With $G=Y^\top Y$ the projection is $P=YG^{-1}Y^\top$, so for two subspaces
\[ \operatorname{tr}(P_aP_b)=\frac{\operatorname{tr}(\operatorname{adj}(G_a)\,A\,\operatorname{adj}(G_b)\,A^\top)}{\det G_a\det G_b},\qquad A=Y_a^\top Y_b, \]
an exact rational number. No orthonormality is assumed and no floating point is used. Run
\begin{verbatim}
python grassmann/verify.py grassmann/packings/m12n3N100.txt
\end{verbatim}
in \url{https://github.com/Ge-limin/math}.


\section{How it was found}
Many random starts of gradient descent on the Grassmannian against a log-sum-exp of the pairwise overlaps, sharpened over time, then a polishing stage (\texttt{grassmann/solve.py}); about 196 seconds on one laptop, with about ten such searches running at once.
