# The 609 cells someone had already filled

*Abridged summary of the model's reasoning, families 001–025.*

The plan was N. J. A. Sloane's *Table of Best Grassmannian Packings*, last modified in 1997. Rows m = 8..16, n = 1..3, N = 51..100 had 1,252 blank cells. A blank cell in a 1997 table is not the same as an open cell in 2026, so before any result was published the model checked whether anyone had filled them since: later papers on Grassmannian and projective packings, the complex "Game of Sloanes" tables, GitHub.

The check found that Henry Cohn now maintains the table at cohn.mit.edu/grassmannian and has extended it. 609 of the 1,252 planned cells already had values there. They were dropped, and the work queue was rebuilt from cells blank in both tables.

That left about 640 cells, short of 719. The model added three kinds of cells, each kept separate in the counts: N = 101..120 inside rows the table extends past 120; rows with n = 4 for m = 9..13; and "sparse rows", where the table lists only one special construction.

What "first" means here: no value in Sloane's table, in Sloane's coordinate files, or in Cohn's table as of October 8, 2026. It is a claim about those tables, checked on that date, not about every computation anyone has run.
